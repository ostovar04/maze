# مزه

وب‌سایت فرانت‌اند فارسی برای انتخاب غذا و جست‌وجوی رستوران‌های نزدیک با نقشهٔ نشان.

## اجرا در VS Code

در ترمینال پوشهٔ پروژه:

```bash
npm install
npm run dev
```

برای خروجی production:

```bash
npm run build
npm run preview
```

## فعال‌سازی نقشه و جست‌وجوی غذای اطراف با نشان

کلید وب نقشه را در `VITE_NESHAN_API_KEY` و کلید Service جست‌وجو را در `VITE_NESHAN_SERVICE_API_KEY` در فایل `.env.local` قرار بده. کلید Service باید مجوز API جست‌وجوی نشان داشته باشد. بعد از تغییر `.env.local`، Vite را متوقف و دوباره اجرا کن. فایل `.env.local` از Git مستثنا شده است. متغیرهای `VITE_` در مرورگر قابل مشاهده‌اند؛ برای کلیدهای وب از دسترسی مناسب و دامنهٔ مجاز استفاده کن.

پس از انتخاب غذا و تعیین موقعیت، پروژه عبارت جست‌وجوی متناظر را از طریق `https://api.neshan.org/v1/search` در اطراف کاربر جست‌وجو می‌کند، نتایج تا شعاع ۵ کیلومتر را بر اساس فاصله مرتب می‌کند و روی نقشه نشان می‌دهد. جست‌وجوی متن مکان‌ها را بر اساس اطلاعات ثبت‌شده در نشان پیدا می‌کند؛ نشان دادهٔ منوی رستوران‌ها ارائه نمی‌کند، پس تطبیق منو باید توسط کاربر/رستوران تأیید شود. اگر سرویس غیرفعال یا کلید نامعتبر باشد، رابط خطا را نمایش می‌دهد و نتیجهٔ ساختگی ارائه نمی‌کند.

موقعیت کاربر با Geolocation مرورگر دریافت می‌شود؛ در حالت دستی باید روی نقشه کلیک کرد. تعیین موقعیت در مرورگر معمولاً به HTTPS یا `localhost` نیاز دارد.

## فناوری‌ها

- Vite و JavaScript خالص
- Three.js برای همبرگر سه‌بعدی متحرک
- `@neshan-maps-platform/maplibre-sdk` برای نقشه

مدل GLB یا تصویر جداگانه لازم نیست؛ همبرگر در Three.js از هندسه‌های سه‌بعدی ساخته می‌شود.
